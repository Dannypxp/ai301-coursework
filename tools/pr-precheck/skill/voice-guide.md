Rule: Acknowledge Version

Write the version of OS, packages used in reproducing the steps

Wrong: ' I ran the issue and the same error pops up'

Right: ' Using macos 27.0 and python 3.9 I was able to confirm the error code: exit(101) running the same steps


Rule: Claim issue


Wrong: 'I want this issue'

Right: ' Ill test this issue version 1.23 and OS Macos and will provide an artificat, I am new and this my first contribution


Rule: Exepected and Actual


Wrong: ' issue was not replicated the same'

Right: ' expected: error 101, Actual: error 101 with same reporduction steps, noted above'
